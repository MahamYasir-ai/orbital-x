# ORBITAL-X

> **"ENGINEERING BEYOND THE KNOWN."**

A world-class, cinematic, experimental aerospace and robotics web application combining NASA-inspired engineering, autonomous planetary exploration, mission control telemetry, and relativistic spacetime warp visualization.

---

## 🚀 Key Features

* **Warp Calibration HUD**: Terminal initialization sequence with system diagnostic progress bars.
* **Persistent WebGL 3D Canvas**: Procedural star warp fields, rotating dimensional portal rings, ion engine plume effects, and interactive planetary bodies built with Three.js.
* **Transforming Aerospace Navigation**: Dynamic HUD navigation bar that morphs its coordinates and telemetry tags as you travel through each sector.
* **Vessel X-01 Flagship**: Interactive 3D spacecraft with 5 functional engineering hotspots (Propulsion, Navigation, Laser Comm, Photovoltaic Sails, AI Core) and a technical blueprint view.
* **Robotics / R-07 Mars Surface**: Extreme environment rover with 98.2% autonomy telemetry, 6-axis sampling arm articulation, 360° stereoscopic mast rotation, and real-time canvas LIDAR radar sweep.
* **World / 04 Survey**: Fictional terrestrial exoplanet featuring an interactive draggable globe and selectable landing zones (Meridiani Chasm, Valles Olympus, Prometheus Crater).
* **Mission Control Flight Console**: Real-time altitude, velocity, ion fuel, and optical signal telemetry with live carrier oscilloscope and Earth-orbit satellite tracker.
* **Dimensional Rupture Event**: Dramatic spacetime distortion anomaly with tensor divergence, singularity collapse, and warp transition into unmapped reality.
* **The Unknown & Multiverse Passage**: Monolithic megastructure void observation and 5-sector reality switcher.
* **Future R&D Lab & Chronology**: Breakthrough engineering pillars and horizontally scrollable timeline from 2026 to 2048 (CLASSIFIED).
* **Mission Archive Vault & Terminal CTA**: Interactive mission dossiers and encrypted project brief dispatch form.

---

## 🛠 Tech Stack

* **Framework**: React 19 + TypeScript
* **Styling**: Tailwind CSS
* **3D Graphics**: Three.js (WebGL)
* **Animation**: Motion (Framer Motion v12)
* **Icons**: Lucide React
* **Build Tool**: Vite

---

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
